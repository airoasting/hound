# 채널: 페이스북

공개 페이지·그룹·게시물에 **지역 정보와 특정 커뮤니티 정보**가 산다(소상공인, 동호회, 지역 모임,
공식 페이지 공지). 로그인 벽이 강한 편이니 **공개 범위만** 쫓는다.

## 긁는 순서

1. **웹 검색.** `WebSearch`로 `site:facebook.com [키워드]`. 공식 페이지·공개 그룹·공개 게시물이 잡힌다.
2. **공개 페이지 열기.** 공개 페이지·게시물 URL을 `WebFetch`로 연다. 공지·소개·공개 글은 보인다.
3. **브라우저 직접 로드.** WebFetch가 로그인 리다이렉트나 빈 화면을 물어오면, 실제 브라우저로 공개
   페이지를 연다([web.md](web.md) 4칸). 로그인 창이 뜨는 지점에서 **멈춘다.**

## 요령 · 가드레일

- 특정 개인의 프로필·타임라인·친구 목록을 캐지 않는다. **개인정보 추적 금지**(SKILL 가드레일).
- 비공개 그룹, 로그인 전용 콘텐츠는 건드리지 않고 "페이스북 로그인/가입 필요"로 보고한다.
- 지역 상호·업체 정보는 페이스북보다 네이버 `search_local`·카카오맵이 더 정확할 때가 많다.
  교차 검증하거나 그쪽으로 갈아탄다.
