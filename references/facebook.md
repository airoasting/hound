# 채널: 페이스북

공개 페이지·그룹·게시물에 **지역 정보와 특정 커뮤니티 정보**가 산다(소상공인, 동호회, 지역 모임,
공식 페이지 공지). 로그인 벽이 강한 편이니 **공개 범위만** 쫓는다. ([access-tiers.md](access-tiers.md) 참조)

## 접근 현실 (실측 2026-11-21)

| 경로 | 결과 |
|---|---|
| 인앱 브라우저 | **본문 확인(11-22).** 로그인 없이 공개 페이지의 팔로워 수, 소개, 최근 게시물이 보였다 |
| Claude in Chrome | 열림(제목만 확인) |
| `WebFetch` | 제목만 있는 빈 셸(약 58자). 본문이 없다 |

## 긁는 순서 (되는 것부터)

1. **웹 검색으로 발견.** `WebSearch`로 `site:facebook.com [키워드]`. 공식 페이지·공개 그룹·공개 게시물
   URL을 얻는다.
2. **인앱 브라우저로 공개 페이지를 연다.** 공지·소개·공개 글을 렌더링된 화면에서 읽는다. 로그인 창이
   뜨는 지점에서 **멈춘다.**
3. **로그인된 크롬.** 공개 그룹 안의 글처럼 로그인해야 보이는 공개 범위가 꼭 필요하면 사용자 허락 하에
   로그인된 크롬(claude-in-chrome)으로 **읽기만** 한다.

`WebFetch`는 빈 셸만 주니 본문 회수에 쓰지 않는다. 페이지 제목 확인 정도로만 쓴다.

## 요령 · 가드레일

- 특정 개인의 프로필·타임라인·친구 목록을 캐지 않는다. **개인정보 추적 금지**(SKILL 가드레일).
- 비공개 그룹, 로그인 전용 콘텐츠는 건드리지 않고 "페이스북 로그인/가입 필요"로 보고한다.
- 지역 상호·업체 정보는 페이스북보다 네이버 `search_local`·카카오맵이 더 정확할 때가 많다.
  교차 검증하거나 그쪽으로 갈아탄다.
