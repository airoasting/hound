# 채널: 슈에추 (雪球, Xueqiu)

중국의 대표 투자 커뮤니티. 주식 시세·종목 토론·개인 투자자 여론이 산다. 중화권 기업·증시의
**심리와 여론**을 읽는 데 쓴다. 다만 **알리바바 클라우드 WAF가 최전방을 막고 있어** 일반 채널보다
회수가 까다롭다. ([access-tiers.md](access-tiers.md) 참조)

## 심볼·URL 형식

| 대상 | 형식 | 예시 |
|---|---|---|
| 종목 페이지 | `xueqiu.com/S/<심볼>` | `xueqiu.com/S/SH600519` (귀주모태), `xueqiu.com/S/AAPL` |
| 개별 글(status) | `xueqiu.com/<uid>/<postid>` | |
| 유저 프로필 | `xueqiu.com/u/<uid>` | |

- A주: 거래소 접두어 필수. 상하이 `SH`+6자리, 선전 `SZ`+6자리 (`SH600519`, `SZ399006`).
- 지수: `SH000001`(상증지수) 등. 미국주: 접두어 없이 티커(`AAPL`, `TSLA`).

## WAF 벽의 현실 (직접 확인)

**plain `WebFetch`로는 내용을 못 얻는다.** `xueqiu.com/S/SH600519`를 그냥 열면 HTTP 200이 오지만,
본문은 종목명·시세·글이 아니라 WAF 토큰과 난독화 블록(`_waf_...`, `aliyun_waf_aa`)뿐이다.
`stock.xueqiu.com/v5/stock/quote.json`은 쿠키 없이 부르면 400을 낸다. **Jina Reader도 안 된다**
(무키 401). 이건 추측이 아니라 관측된 사실이다.

## 긁는 순서 (현실 경로)

1. **웹 검색으로 발견.** `WebSearch`로 `site:xueqiu.com [종목/키워드]`(중국어, 종목 코드도). 검색 결과
   스니펫만으로도 "무엇이 논의되는지"의 방향은 잡힌다.
2. **실제 브라우저 세션으로 읽기(정공법).** WAF는 정상 브라우저의 JS 실행과 쿠키를 통과시킨다. 사용자
   허락 하에 이미 로그인된 크롬(claude-in-chrome)이나 인앱 브라우저로 종목·글 페이지를 열면 렌더링된
   시세·토론·지표가 보인다. **읽기까지만** 하고 벽은 뚫지 않는다.
3. **(심화) 쿠키를 세운 뒤 공개 JSON.** 홈(`xueqiu.com`)을 한 번 열면 서버가 `xq_a_token`·`acw_tc`
   쿠키(약 30분)를 심는다. 그 쿠키를 실어 보내면 아래 엔드포인트가 열린다. **WAF는 `xueqiu.com`·
   `stock.xueqiu.com`은 막지만 `api.xueqiu.com` 도메인은 통과시킨다.**
   - 시세: `stock.xueqiu.com/v5/stock/quote.json?symbol=<심볼>&extend=detail`
   - 종목 토론: `api.xueqiu.com/statuses/stock_timeline.json`
   - 글 검색: `xueqiu.com/statuses/search.json?q=<키워드>&count=&page=`
   엔드포인트 스펙은 예고 없이 바뀌니 하드코딩하지 말고 실패하면 2번(브라우저)으로 내려간다. IP가
   마킹되면 캡차(`acw_sc__v2`)로 격상돼 브라우저가 필요해진다.

## 챙길 숫자

- 글 단위: 转发(리포스트), 评论(댓글), 点赞(좋아요), 조회수, 작성시각.
- 유저: 关注·粉丝(팔로잉·팔로워 수).
- 시세: 현재가·등락률·거래량·시총 (`quote.json`).

## 요령 · 가드레일

- 중국 상장사 여론·투자심리 파악용이다. 시세·재무 **사실**은 공식 소스(거래소·공시, [DART/opendart])와
  반드시 교차 검증한다. 개별 글은 개인 의견이지 사실이 아니다.
- **투자 조언은 하지 않는다.** "누가 어떤 의견을 냈다"는 관찰만 회수하고, 매수·매도 판단으로 바꾸지
  않는다. 개인화된 투자 자문은 스킬 가드레일이자 안전 규칙 위반이다.
- 로그인·쿠키 벽은 우회하지 않고 "슈에추 로그인/세션 필요"로 정직하게 보고한다.
