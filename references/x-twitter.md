# 채널: X (트위터)

실시간 여론, 속보, 당사자의 직접 발언이 사는 곳. 대신 **상당수가 로그인 벽 뒤**에 있다.
공개 콘텐츠만 쫓고, 벽을 만나면 뚫지 말고 정직하게 보고한다.

## 긁는 순서 (사다리)

1. **웹 검색으로 공개 게시물 찾기.** `WebSearch`로 `site:x.com [키워드]` 또는
   `site:twitter.com [키워드]`. 특정 인물이면 `from:핸들 키워드` 형태의 표현도 시도한다.
2. **공개 게시물 본문 열기.** 찾은 게시물 URL을 `WebFetch`로 연다. 공개 트윗은 본문·작성자·날짜가 보인다.
3. **공개 미러.** 로그인 없이 보이는 공개 미러(nitter 계열 등)가 살아 있으면 본문 확보에 쓴다.
   미러는 자주 죽으니 하나 막히면 다음 것으로 갈아탄다.
4. **브라우저 직접 로드.** WebFetch가 JS 껍데기만 물어오면 실제 브라우저로 게시물 페이지를 연다
   ([web.md](web.md) 4칸). 타임라인이 로그인을 요구하는 지점에서 **멈춘다.**

## 검색어 요령

- 한국 이슈는 한국어로, 글로벌 이슈·해외 인물은 영어로 각각 판다.
- 해시태그(`#키워드`)와 인용구를 그대로 넣으면 특정 반응 덩어리를 잡기 좋다.
- 속보성은 시점을 좁혀("2026 7월 ...") 최근 것만 걸러낸다.

## 로그인 벽 (반드시 지킨다)

- 검색·공개 게시물까지만. 로그인해야 보이는 타임라인·비공개 계정·팔로워 전용은 **건드리지 않는다.**
- 벽을 만나면 "여기부터는 X 로그인이 필요하다"고 보고하고, 대신 그 이슈를 다룬 뉴스·블로그로
  채널을 갈아타 우회 정보를 찾는다.
