# 채널: X (트위터)

실시간 여론, 속보, 당사자의 직접 발언이 사는 곳. 대신 **X 소유 도메인은 `WebFetch` 접근이 막혀 있고**
타임라인·검색은 로그인 벽 뒤다. 특정 트윗 하나는 fxtwitter API로 읽는다.
([access-tiers.md](access-tiers.md) 참조)

## 접근 현실 (실측 2026-11-21)

| 경로 | 결과 |
|---|---|
| `api.fxtwitter.com` (`WebFetch`) | 됨. 본문과 좋아요 등 숫자가 JSON으로 온다 |
| `api.vxtwitter.com` | 403. 더 이상 쓰지 않는다 |
| x.com (`WebFetch`) | 402 Payment Required |
| 인앱 브라우저 | **본문 확인(11-22).** 로그인 없이 트윗 텍스트가 보인다. 좋아요·리트윗 숫자는 보이지 않았다 |
| Claude in Chrome | 열림(제목만 확인). 로그인 상태의 검색·타임라인은 재지 않았다 |

- **Nitter는 죽었다.** nitter.net(빈 셸)·xcancel.com(브라우저 검증 챌린지)·poast(503) 등 공개
  인스턴스는 자동화로 못 뚫는다(2024년 X가 게스트 계정을 없앤 여파). **의존하지 않는다.**
- **검색·타임라인·보호 계정은 로그인 벽.** 실제 로그인 세션이라야 열린다.

## 긁는 순서 (되는 것부터)

1. **트윗 발견.** `WebSearch`로 `[키워드] X` 또는 인물·핸들을 넣어 트윗 URL/ID를 찾는다. 뉴스·블로그가
   특정 트윗을 인용한 경우도 많으니 거기서 URL을 주워도 된다.
2. **단일 트윗 읽기: fxtwitter JSON API.** 트윗 URL에서 핸들과 status ID를 뽑아
   `https://api.fxtwitter.com/<핸들>/status/<ID>`를 `WebFetch`로 연다. **본문 전문 + 좋아요·리트윗·댓글·
   조회수 + 작성자(팔로워 수)**까지 JSON으로 온다. 무키·무계정. 제3자 운영이라 죽을 수 있다.
3. **fxtwitter가 안 되면 인앱 브라우저.** 같은 트윗 URL(`x.com/<핸들>/status/<ID>`)을 인앱 브라우저로
   열어 렌더링된 본문을 읽는다. 로그인 없이 공개 트윗은 보인다.
4. **검색·타임라인·보호 계정: 로그인된 크롬.** 키워드 검색이나 한 계정의 흐름 전체는 위 경로로 안
   된다. 꼭 필요하면 사용자 허락 하에 로그인된 크롬(claude-in-chrome)으로 **읽기만** 한다. 로그인을
   요구하는 지점에서 **멈춘다.**

## 검색어 요령

- 한국 이슈는 한국어로, 글로벌 이슈·해외 인물은 영어로 각각 판다.
- 해시태그(`#키워드`)와 인용구를 그대로 넣으면 특정 반응 덩어리를 잡기 좋다.
- 속보성은 시점을 좁혀("2026 7월 ...") 최근 것만 걸러낸다.

## 챙길 숫자

fxtwitter 응답에서 **팔로워 수, 좋아요·리트윗·인용·댓글 수, 조회수**를 함께 회수한다.
장문 트윗은 `is_note_tweet`로 구분되고 커뮤니티 노트도 응답에 담긴다. 브라우저로 읽었으면 화면에 보이는
숫자만 적는다.

## 로그인 벽 (반드시 지킨다)

- 로그인 없이는 단일 공개 트윗까지만. 로그인해야 보이는 타임라인·비공개·보호 계정은 사용자 허락 없이
  **건드리지 않는다.**
- 벽을 만나면 "여기부터는 X 로그인이 필요하다"고 보고하고, 그 이슈를 다룬 뉴스·블로그로 채널을 갈아타
  같은 정보를 찾는다.
